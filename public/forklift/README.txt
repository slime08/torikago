フォークリフト倉庫パズル Web版 (単一HTMLファイル)

タイトル画面＋全5ステージ版。
・プレイ中の「手数」と各ステージの「最短手数」を表示
・クリア時に S / A / B ランクを表示 (S = 最短以内、A = 最短×1.3 以内、B = クリア)
・自己ベストランクはブラウザに保存され、タイトル画面のステージボタンに
  「★S」のように表示される (「クリア済み n/5　Sランク m/5」の集計行つき)

最短手数: ステージ1=34手, 2=46手, 3=52手, 4=68手 (ソルバーで厳密に確定),
ステージ5=100手 (確認済みの最速。探索空間が大きく厳密な証明は未完だが、
2億状態以上の探索でもこれ未満の解は見つかっていない)

1. この forklift フォルダごと、Astro プロジェクトの public/ の中に入れる
   (public/forklift/index.html になるように)
2. ビルド＆デプロイすると https://torikago.net/forklift/ で遊べる
3. サイト内のページからリンクを張る場合は <a href="/forklift/"> のように書く

ファイルは index.html 1つだけ (画像も全部埋め込み済み、約67KB)。
サーバー側の設定 (ヘッダ等) は不要。
